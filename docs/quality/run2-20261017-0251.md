**To fix before this becomes the staging CI gate**, chosen now and set before the next run:

## Found about the assistant, not yet fixed

1. **"Right now" in the app.** Two models counted each stay's latest score instead of the latest
   hour, which brings in patients who have gone home. Genie doesn't make this mistake: its space
   says what "now" means. One line in the app's table notes would close it ("patients on the ward
   now = rows at `prediction_ts` = now").
2. **The model card's "Reading it" paragraph** compares version 3 with version 1 and with NEWS2
   in the same sentences. Three of the six d5 answers took a version 1 statement for a NEWS2 one.
   Splitting it into two sentences, one per comparison, would help every model.
3. **The answer limit and reasoning.** For gpt-5 models, the 1,200-token limit includes hidden
   reasoning. A model that thinks for long returns nothing, and the visitor sees "I couldn't
   produce an answer". It doesn't happen in the app today, which sends gpt-5-mini `none`, but any
   heavier setting needs more room.
4. **The tested setting is not always the shipped one.** This test sent no reasoning setting.
   The app sends gpt-5.5 `none` and GPT-OSS `low` (`chat/models.yaml`). Ship the setting that was
   tested, or test the setting that ships.
